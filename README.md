# Telegram-бот для сайта

Стартовый бот с кнопками «Поддержка», «Доставка», «Контакты» и переходом на сайт. Токен хранится в переменной окружения `BOT_TOKEN`, а не в исходном коде.

## Перед запуском

1. В Telegram откройте официальный `@BotFather`, выберите `/mybots` → нужный бот → **API Token** и отзовите оба токена, которые уже отправляли в чат. Создайте новый токен или выпустите новый для выбранного бота. Новый токен никому не отправляйте.
2. Запустите бота, откройте его в Telegram, нажмите `/start`, затем `/myid`. Бот покажет ваш числовой ID — укажите его в `ADMIN_CHAT_ID` и перезапустите бота. Так бот сможет отправлять вам обращения.
3. Замените тексты `DELIVERY_TEXT` и `CONTACT_TEXT` на настоящие условия и контакты.

## Локальный запуск в Windows PowerShell

Установите Python 3.10 или новее, откройте PowerShell в папке проекта и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:BOT_TOKEN = "НОВЫЙ_ТОКЕН"
$env:ADMIN_CHAT_ID = "ЧИСЛОВОЙ_ID_АДМИНИСТРАТОРА"
$env:SITE_URL = "https://site-197da.firebaseapp.com/"
python bot.py
```

Оставьте окно PowerShell открытым: пока программа запущена, бот отвечает. Для проверки откройте чат с ботом и отправьте `/start`.

## Постоянный хостинг через Render

Боту нужен постоянно работающий процесс. Удобный вариант — Render **Background Worker**:

1. Загрузите эту папку в свой GitHub репозиторий. Не загружайте `.env` и не записывайте токен в файлы.
2. В Render создайте **New → Background Worker** и подключите репозиторий.
3. Укажите Build Command `pip install -r requirements.txt`, Start Command `python bot.py`.
4. В разделе **Environment** добавьте переменные `BOT_TOKEN`, `ADMIN_CHAT_ID`, `SITE_URL`, `DELIVERY_TEXT`, `CONTACT_TEXT` и сохраните/задеплойте.
5. После успешного запуска проверьте `/start` в Telegram.

Render берёт исходный код из GitHub, а секреты задаются отдельно в панели сервиса. Постоянно работающий worker может быть платным; проверьте актуальные тарифы Render перед выбором плана.

## Как работает поддержка

Пользователь выбирает «Поддержка» и присылает сообщение. Бот пересылает копию администратору, а администратор отвечает на неё в чате с ботом. Бот отправляет ответ пользователю. Связи ответов пока хранятся в памяти процесса и сбрасываются после перезапуска. Для небольшого первого запуска это подходит; для надёжной поддержки стоит добавить базу данных.

## Связь с сайтом

Сейчас бот содержит ссылку на сайт, но не подключён к базе данных сайта и не видит заказы. Чтобы добавить форму заказа внутри Telegram или обмен данными с сайтом, понадобятся API/серверная часть сайта и описание того, как на сайте хранятся и оформляются заказы.
